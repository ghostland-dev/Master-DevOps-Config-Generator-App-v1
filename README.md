# DevOps Config Generator

Generates YAML configuration for DevOps tooling with syntax-highlighted previews.

## Features

- YAML generation
- Syntax-highlighted preview
- React + TypeScript + Tailwind

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
git clone https://github.com/ghostland-dev/devops-config-generator.git
cd devops-config-generator
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
